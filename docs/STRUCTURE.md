# Структура книги

Три рівні, і в кожного одне місце в репозиторії.

## Історія

**Одне питання. Один розділ тексту. Одна концепція.** Це найменша одиниця
книги й те, що дитина читає за раз: видиме явище → питання → перевірка →
наступні питання.

У репозиторії історія — це **сходинка ланцюжка** плюс **свій файл прози**:

```yaml
# content/03 - chains/03 car-trip.md — місце в порядку
- concept: evaporation-is-invisible
  question: Куди поділася калюжа, якщо її ніхто не випив?
```

```yaml
# content/stories/<глава>/<NN назва>.<мова>.md — текст
id: spoon
lang: uk
title: "Чому ложка не розчиняється в чаї?"
chapter: strange-moves-in
concepts: [three-states, everything-has-a-melting-point]
status: draft
```

Номер у назві файлу — для файлового браузера, `.uk` — мова, решта — id.
Одна історія може нести кілька концепцій: так живуть «пасажири» — концепції без
власної перевірки, які їдуть усередині сусідньої історії.

**Попередньої й наступної у файлі немає.** Порядок записаний у главі один раз,
і сусіди обчислюються з нього. Переставити історію — одна правка в ланцюжку.

Три види сходинки:

| вид | що означає |
| --- | --- |
| `spine` (за замовчуванням) | несуча: не може стояти раніше за свої передумови |
| `delight` | цікавинка: вирізна, на неї не має права спиратися жодна спина — зокрема й у наступних главах |
| `seeded` | висновок без механізму: передумови не вимагаються, але `defers:` обов'язковий, і борг іде в блокнот Ади |

## Глава

**Набір історій, об'єднаних обставинами**, а не темою: один вечір, одна
поїздка, один берег. У репозиторії глава — це файл у `content/03 - chains/`,
а її проза — папка в `content/stories/` з файлом на історію.

Главу можна читати цілою: `/chapters/<id>/` зшиває її історії в порядку
ланцюжка. Файл — одиниця роботи, глава — одиниця читання.

Глава спирається на все, що пройдено в главах до неї, і ні на що з того, що
буде після. Перевіряє `npm run chain`.

## Книга

**Упорядкований список глав** — `content/03 - chains/_book.yml`:

```yaml
title: Книга перша
target: [60, 100]
chapters:
  - strange-moves-in
  - round-on-the-pillows
  - car-trip
```

Ціль — **60–100 історій**, тобто 5–8 глав по 10–15.

**Перетасувати книгу = переставити рядки в цьому списку.** Більше нічого
правити не треба: порядок глав не записаний у самих главах. Поле `follows:`
в ланцюжку лишається тільки для того, що в книгу не входить.

Ланцюжок, якого немає в `_book.yml`, — не глава, а план або пул (так зараз
живе `01 book-one.md`). Книга не має права на нього спиратися.

## Що з чого виростає

Граф концепцій (`content/02 - concepts/`) — не книга, а запас: 300+ вузлів,
з яких книга бере 60–100. `npm run select` показує, які концепції несуть
найбільше, `npm run chain` — чи тримається порядок, `/notebook/` — що книга
пообіцяла й ще не пояснила.
